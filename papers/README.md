# Papers

Guarda aquí los PDFs (git los ignora). Convención de nombre:

```
AAAA_primer-autor_titulo-corto.pdf
```

Por ejemplo `2017_vaswani_attention-is-all-you-need.pdf` o `2003_bengio_neural-probabilistic-lm.pdf`.

Las notas de cada paper van en `../notas/` con el mismo nombre base y extensión `.md`.
